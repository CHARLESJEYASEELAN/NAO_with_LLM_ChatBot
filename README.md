# NAO Robot Audio Chatbot

Hi! This is my NAO Robot Audio Chatbot project. I made a cool robot in Webots, a free simulator, that chats with you. You type a message, and NAO answers using AI, speaks the reply out loud, and nods its head like it’s talking to you. It’s a fun way to learn about robotics and AI!
Watch it in action: YouTube Demo
What My Project Does

You type something like “Hi, NAO!” in Webots.
- NAO uses AI to reply with a smart answer.
- NAO speaks the answer using a computer voice.
- NAO nods its head while talking to look friendly.

## Tools I Used

1. Webots: A free program to simulate NAO.
2. Python: The code runs in Python 3.10.
3. Mistral AI: Makes NAO’s replies smart.
4. pyttsx3: Turns text into speech.
5. Windows 11: My computer (it might work on Mac or Linux too).

## How I Built It

I set up Webots and added a NAO robot.
I wrote a Python program to:
Read what you type.
Get answers from Mistral AI.
Make NAO speak and nod.

I tested it by typing messages and watching NAO respond!
